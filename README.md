# آوند آسانسور

وب‌سایت تک‌صفحه‌ای فارسی برای معرفی نمونه‌ای یک مجموعه خدمات آسانسور، با رابط راست‌چین، حالت روشن و تاریک، ناوبری واکنش‌گرا و محتوای معرفی خدمات و دانش فنی.

## فناوری‌ها

- HTML5 معنایی
- CSS3 با متغیرهای متمرکز و فایل مستقل واکنش‌گرایی
- JavaScript بدون فریم‌ورک
- تصاویر WebP محلی
- لوگو، آیکون‌ها و گرافیک‌های SVG مستقل

## اجرا

پوشه پروژه را در VS Code باز کنید و فایل `index.html` را در مرورگر اجرا کنید. برای تجربه توسعه بهتر می‌توانید از افزونه Live Server استفاده کنید؛ اجرای پروژه به سرور یا بک‌اند نیاز ندارد.

## شخصی‌سازی برند

نام «آوند آسانسور» و نشان گرافیکی آن هویت نمونه پروژه هستند. پیش از انتشار برای یک شرکت واقعی، نام برند، لوگو، متن معرفی و اطلاعات تماس را با داده‌های تأییدشده جایگزین کنید.

- لوگوی مستقل: `assets/logos/wordmark.svg`
- نشان مستقل: `assets/logos/mark.svg`
- رنگ‌ها و مقادیر طراحی: ابتدای `css/style.css`
- متن‌ها و ساختار صفحه: `index.html`
- رفتارهای تعاملی: `js/script.js`

## اطلاعات تماس

در این نسخه شماره تلفن، ایمیل، نشانی و لینک شبکه اجتماعی ساختگی قرار نگرفته است. پس از دریافت اطلاعات رسمی می‌توانید جایگزین‌های بخش ارتباط را به لینک‌های `tel:`, `mailto:` و نشانی معتبر نقشه تبدیل کنید.

## تصاویر و فونت

تصاویر به‌صورت فایل محلی WebP در پوشه‌های موضوعی نگهداری شده‌اند. لوگوها، آیکون‌ها و گرافیک‌های SVG نیز فایل‌های مستقل و قابل ویرایش هستند. فونت Noto Sans Arabic در سه وزن Regular، Medium و Bold به‌صورت محلی در `assets/fonts/` قرار گرفته است و برای نمایش فارسی به منبع خارجی وابسته نیست.

## نکات انتشار

- دامنه نهایی را مشخص و canonical را در صورت نیاز اضافه کنید.
- اطلاعات واقعی شرکت، نشانی، تلفن، ایمیل و شبکه‌های اجتماعی را وارد کنید.
- نمونه‌های تصویری پروژه را با نمونه‌کارهای مجاز و واقعی جایگزین کنید.
- پیش از انتشار نهایی، متن‌ها، مجوز تصاویر و اطلاعات تماس را بازبینی کنید.

این پروژه هیچ بک‌اند، پایگاه داده، API، CMS، فرم دریافت اطلاعات یا سیستم ذخیره اطلاعات کاربران ندارد.
